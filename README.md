# SalesManagement_SysDev プロジェクト

このディレクトリは、`SalesManagement_SysDev.sln` に含まれる現在の WPF 実装プロジェクトです。

## 利用者向け情報

起動手順、サンプルアカウント、受注登録・受注管理の操作については、ルートの [README.md](../README.md) を参照してください。

## このプロジェクトの画面

- ログイン・セッション管理
- メインメニュー
- 受注管理（一覧、検索、確定、非表示、詳細）
- 受注登録
- 商品、顧客、在庫、出荷、販売の既存業務画面

- 開発作業ガイド: [../CLAUDE.md](../CLAUDE.md)

## 制約

- 既存 SQL Server LocalDB `SalesManagement` と EF Core エンティティを使用します。
- 受注の非表示は管理フラグを `2` にする方式です。
- 取引データは物理削除しません。
- 実行中のアプリが出力ファイルをロックしている場合、ビルド前にアプリを終了してください。
